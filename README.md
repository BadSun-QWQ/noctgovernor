# 司夜罗盘 · 服务器站点

纯静态站点（HTML + CSS + JS，零构建、零依赖）。**单文档多视图**：首页 / 历程 / 风景 / 合照 / 成员都在 `index.html` 里，通过 hash 切换，切换时不刷新页面——这是 BGM 能连续播放的关键。

## 这份是 GitHub 版

与 `司夜罗盘` 文件夹的区别：**所有资源路径前面都加了 `/noctgovernor`**（例如 `/noctgovernor/assets/css/style.css`），对应 GitHub Pages 的项目站点地址：

```
https://<你的用户名>.github.io/noctgovernor/
```

- 仓库名必须是 `noctgovernor`（区分大小写，与路径一致）
- 上传后从上面的网址访问；**不要双击本地 index.html**，绝对路径在 `file://` 下会失效（本地预览用原来那份 `司夜罗盘`）
- GitHub Pages 开启方式：仓库 Settings → Pages → Source 选 `main` 分支 `/ (root)` → 保存

## 打开方式

本地预览请用原来的 `司夜罗盘` 文件夹；这份需要通过 GitHub Pages 访问。地址形如：

```
index.html            首页（资源路径带 /noctgovernor 前缀）
index.html#history    历程（含完整发展历程尺）
index.html#scenery    服务器风景
index.html#photos     合照墙
index.html#members    成员信息
index.html#news-all   全部公告（12 条）
```

## 首页结构

1. **Hero**：10 张实拍轮播背景（每 5 秒）＋ 标题与标语 ＋「轻触屏幕以继续」
2. **最新公告**：五块 Minecraft 风格木告示牌，日期 + 类型标签（活动 / 更新 / 通知）+ 标题；每块牌子两角各有一簇沿直角边生长的樱花：大小错落，深色的一层压在木板边缘（被挡住半边，像从牌后探出来），浅色的一层压在木板上；整体随呼吸轻摆，点击樱花会炸开一捧花瓣再飘落消失；下方「更多公告」按钮四周绕着一圈大小不一、前后错落的樱花，点击进入公告页
3. **世界的一角**：实拍图 + 三个入口
4. **服务器发展历程尺**：六期横向排列，可拖动 / 滚轮 / ← → / 按钮翻动，悬停有浮起与光效

原先的「服务器状态」栏已移除；状态相关文件（`config.js`、`status.js`）也已删除。
公告已上调到原来历程的位置，历程顺延到最后。首页只展示最近 5 条，其余在 `#news-all` 公告页。

## 公告怎么改

数据在 `assets/js/news.js` 的 `NEWS` 数组，条目按数组顺序（从新到旧）渲染：

```js
{ date: '2026.11.01', type: 'notice', title: '新周目开启：樱花街落成' }
```

- `type` 取 `event`（活动，绿） / `update`（更新，金） / `notice`（通知，纸色），未知值会自动按 `notice` 处理。
- 超过六条会自动往下排，卡片样式与悬停动效自动套用。
- 标题、日期仍是占位的地方写成了 `【待填：…】`，直接替换即可。

## 发展历程尺怎么改

六期数据集中在 `assets/js/eras.js` 顶部 `ERAS` 数组，首页与「历程」页共用同一份数据，改一次两处同步：

```js
{
  name: '宝可梦重铸',
  since: '2024.03',            // 开服时间
  version: '1.20.1',           // 版本号
  cover: 'assets/img/era-1.jpg', // 可选：放了封面就替换占位
  text: '一句话描述',
  live: false                  // 最后一期填 true，会显示「进行中」徽章
}
```

- **开服顺序**：宝可梦重铸 → 养老之家 → 龙之冒险 → 方可梦一期 → 惊变一百天 → 方可梦二期（数组顺序即显示顺序）。
- **不放 `cover` 时**，封面位显示占位图（罗盘水印 + 「封面待上传」），卡片右上角仍有期数编号。
- 增删期数后，`.eras-count` 的「06 期」会自动按数组长度更新。

## 视觉与交互

- **质感**：全站胶片颗粒叠加、顶部金色阅读进度条、Hero 暗角、卡片顶部内高光、主按钮掠光。
- **历程尺**：卡片悬停上浮 8px、边框转金、节点发光、封面掠光；尺子横线与节点圆点对应每一期。
- **视图切换**：新视图淡入上浮（`pageIn`），页头文字逐行重播入场。
- **文字入场**：`.intro` 依次延迟 0.1–0.6s 浮起（纯 CSS）。
- **滚动显示**：视口内 `.reveal` 卡片淡入，小节标题金色下划线从左扫过。
- **灯箱**：点击图片放大，`←` `→` 切换，`Esc` 关闭。
- **音乐**：右下角浮窗，切页不断播；暂停状态跨页保留；刷新后恢复进度并尝试续播。
- **无障碍**：`prefers-reduced-motion` 下关闭动画；键盘可用；焦点可见；历程尺可 Tab 聚焦后用方向键。

## 需要你补的地方

1. **历程尺数据**：`assets/js/eras.js` 里的开服时间、版本号、封面（六期）。
2. **成员名单与头像**：名单改为数据驱动，写在 `assets/js/members.js` 的 `MEMBERS` 数组里。

   ```js
   { name: '【待填：昵称】', role: '建筑师 · Builder', since: '2024.06', bio: '空。' }
   // 加头像就补一行：avatar: 'assets/img/avatars/xxx.png'
   ```

   - **每个卡槽都有头像**：填了 `avatar` 显示照片，没填会自动生成一张 8×8 像素脸（配色按序号轮换），不会出现空图标。
   - **新增成员**：复制一条记录即可，头像位、卡片样式、入场动画都会自动套用。
   - 头像建议 256×256 PNG，放在 `assets/img/avatars/`。
   - 当前 `badsun.png` 在服主卡、`0rangy.png` 在 0rangy 卡。
3. **公告与时间线**：`#home` 的 4 条公告、`#history` 的 7 条时间线。
4. **图片**：`assets/img/` 下 10 张轮播图已压到 1920px；替换风景/合照按 `tile` 的四处属性改。

## BGM

`assets/audio/bgm.flac`（41.4 MB，FLAC 无损，1:56）。

## 部署

整个目录直接上传：Cloudflare Pages（拖文件夹）、GitHub Pages、Nginx/宝塔。开启自定义 404 指向 `404.html`。hash 路由不需要服务器 rewrite 规则。

## 已知限制

- 没有后端与数据库：所有内容都是手写 HTML / JS 数据。
- 浏览器可能因省电策略暂停后台标签页的音乐，切回后点播放键继续。
- 刷新后自动续播若被浏览器拦截，会保持暂停（自动播放策略，站点无法绕过）。
- 发展历程尺在触屏上用原生横向滑动，桌面端支持鼠标拖动与滚轮横向滚动。
